
# Agente Financeiro com IA 🤖

Projeto desenvolvido com n8n para auxiliar no gerenciamento de contas e boletos utilizando inteligência artificial.

## 🎯 Objetivo

Automatizar o cadastro, a consulta e a atualização de pagamentos, além de enviar lembretes por e-mail sobre contas próximas do vencimento.

## 🛠️ Tecnologias utilizadas

- n8n
- Groq
- Google Sheets
- Gmail
- IA generativa

## ⚙️ Funcionalidades

- Cadastro de contas e boletos.
- Consulta de contas pendentes e pagas.
- Atualização do status de pagamento.
- Identificação de boletos com vencimento em 7 dias.
- Envio automático de lembretes por e-mail.

## 🔄 Como funciona

O projeto possui dois fluxos principais:

1. Agente financeiro interativo.
2. Automação de lembretes de vencimento.
